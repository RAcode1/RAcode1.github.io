Retrieval broke one safety case. The tests caught it before release; after the fix, that case and 3 related ones pass.

  • Retrieval broke a safety case, and the tests caught it. A war-story request for a 5-year-old pulled in the grief guide. My first fix didn't hold; the second did.
  • One run isn't proof. 3 of 10 cases flipped between identical runs, so I judge changes on repeated runs.
  • The cheaper model wasn't worth it. Haiku was 57% cheaper but passed 13 points fewer cases and missed a child-safety case, so the app stays on Sonnet.
  • A prompt rule only moved the problem. Banning "Mia" and "Maya" (43 of 70 stories) made "Pip" and "Priya" the new favorites. Names need to be picked in code.
  • The test harness had a bug too. The judge's 3,000-token limit cut off one grading. It's 8,000 now.
