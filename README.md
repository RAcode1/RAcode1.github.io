# Working demos · [racode1.github.io](https://racode1.github.io)

Interactive demos of my AI projects, built with Claude Code:

1. **MindSprout:** a parent picks a lesson and Claude writes a 6-page story that teaches it.
2. **How I test MindSprout:** 70 test cases, a second Claude model as judge, and attempts to break it.
3. **Morning email digest:** my inbox sorted like a support queue.
4. **Family help desk:** my family's tech questions become tickets, with a scam check.

Every demo plays back real output saved from the apps (`data.js`), so the page needs no API key
or sign-in and costs nothing to view.
